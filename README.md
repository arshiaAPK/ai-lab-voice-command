# تشخیص دستور صوتی

## ۱. معرفی پروژه

این پروژه مربوط به درس آزمایشگاه هوش مصنوعی است. هدف آن بررسی روش‌های تشخیص دستورهای صوتی و شناسایی فرمان‌های ساده از طریق ورودی صوتی است.

## ۲. تعریف مسئله با روش PEAS

| بخش | توضیحات |
|---|---|
| Performance Measure (معیار عملکرد) | دقت تشخیص دستورهای صوتی و کاهش خطای تشخیص |
| Environment (محیط) | محیطی که کاربر در آن فرمان صوتی صادر می‌کند |
| Actuators (عملگرها) | نمایش دستور تشخیص‌داده‌شده یا اعلام نتیجه تشخیص |
| Sensors (حسگرها) | میکروفون یا فایل صوتی ورودی |

## ۳. ویژگی‌های محیط

| ویژگی محیط | نوع |
|---|---|
| قابل مشاهده بودن | تا حدی قابل مشاهده |
| قطعی یا احتمالی بودن | احتمالی |
| اپیزودیک یا پی‌درپی بودن | اپیزودیک |
| ایستا یا پویا بودن | پویا |
| گسسته یا پیوسته بودن | پیوسته |
| تک‌عاملی یا چندعاملی بودن | تک‌عاملی |

## ۴. هدف ارزیابی

عملکرد سیستم با استفاده از معیار دقت (Accuracy) ارزیابی می‌شود. هدف، تشخیص درست فرمان‌های صوتی و کاهش اشتباه در شناسایی آن‌ها است.
