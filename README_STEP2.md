# گام دوم پروژه: تشخیص دستور صوتی
## مسئولیت: داده و ارزیابی

این بسته زیرساخت جمع‌آوری، کنترل کیفیت، تقسیم داده و ارزیابی را آماده می‌کند. **این بسته شامل داده صوتی واقعی یا نتیجه آزمایش واقعی نیست.** ابتدا اعضای گروه باید صداها را ضبط کنند؛ سپس اسکریپت‌ها را اجرا کنید.

### تعریف داده
- کلاس‌ها: `روشن`، `خاموش`، `شروع`، `توقف`، `کمک`
- تعداد اعضا/گویندگان: ۴ نفر
- تعداد پیشنهادی: هر نفر ۱۰ نمونه از هر دستور
- مجموع هدف: ۴ × ۵ × ۱۰ = ۲۰۰ فایل WAV
- فرمت: WAV، تک‌کاناله (Mono)، نرخ نمونه‌برداری ۱۶۰۰۰ هرتز، PCM 16-bit
- شناسه گوینده: `spk01` تا `spk04`؛ از نام واقعی افراد در نام فایل استفاده نکنید.

### ساختار پوشه
```text
data/
```

### نصب
در ترمینال، از پوشه اصلی پروژه:
```bash
pip install -r requirements-step2.txt
```

### ضبط نمونه‌ها
برای هر گوینده و هر دستور، دستور زیر را ۵ بار برای شمارش ۱۰ اجرا کنید یا `--count 10` بگذارید:
```bash
python scripts/record_audio.py --speaker spk01 --label روشن --count 10
```
برای پنج دستور و چهار گوینده، این کار باید برای هر ۲۰ ترکیب انجام شود. هر بار دستور را طبیعی و با مکث کوتاه بگویید. ضبط‌ها را در محیط نسبتاً آرام انجام دهید. بهتر است فاصله میکروفون ثابت باشد.

### تقسیم آموزش و آزمون
فایل‌های `splits/train_speakers.txt` و `splits/test_speakers.txt` را بررسی کنید. طرح اولیه:
- آموزش: `spk01` و `spk02`
- آزمون: `spk03` و `spk04`

هیچ گوینده‌ای نباید هم‌زمان در آموزش و آزمون باشد. این کار آزمون را سخت‌گیرانه‌تر می‌کند و بررسی می‌کند مدل روی صدای افراد دیده‌نشده چطور عمل می‌کند. با ۴ گوینده، نتیجه فقط یک ارزیابی مقدماتی است و برای ادعای تعمیم‌پذیری قوی کافی نیست.

### کنترل کیفیت و ساخت manifest
```bash
python scripts/prepare_dataset.py
```
در صورت موفقیت، فایل `data/processed/manifest.csv` ساخته می‌شود. اگر اسکریپت خطا داد، پیام خطا را بخوانید؛ فایل خراب/ساکت/با مشخصات نامعتبر را دوباره ضبط کنید. فایل‌های خام را پاک نکنید تا نسخه اصلاح‌شده قابل ردیابی باشد.

### ارزیابی مدل در مرحله مدل‌سازی
پس از آنکه مدل روی مجموعه آزمون پیش‌بینی تولید کرد، فایل CSV با دو ستون `true_label,predicted_label` بسازید و اجرا کنید:
```bash
python scripts/evaluate_predictions.py --input predictions.csv
```
اسکریپت Accuracy، Precision، Recall و F1 هر کلاس و ماتریس درهم‌ریختگی را گزارش می‌کند. تا قبل از اجرای مدل و داشتن پیش‌بینی‌های واقعی، هیچ عددی برای عملکرد مدل گزارش نکنید.

### نکته مهم درباره GitHub
فایل‌های صوتی خام، صدای افراد و اطلاعات هویتی را در مخزن عمومی قرار ندهید مگر همه افراد رضایت روشن داده باشند و استاد صریحاً خواسته باشد. کد، مستندات، فایل split و manifest بدون داده هویتی را می‌توانید commit کنید. حجم و حریم خصوصی داده را با استاد هماهنگ کنید.
